# 当前能力与限制

当前阶段通过获取源码、安装依赖和本地启动来使用 Origamix。官网暂不提供安装包下载。

## 已有能力

- Electron 桌面工作台与本地目录授权。
- 页面可视化编辑、带事件子项的大纲树、Agent 对话和沙箱预览。
- 项目唯一的布局配置：预设、拖拽、布局对话、版本与显式应用，以及完整应用导航预览。
- 逻辑流编排与函数配置，包括请求、条件、属性、方法、变量、显隐和弹窗操作。
- 保留 Working 草稿、显式保存版本、查看和恢复历史。
- 显式应用到本地项目、显式项目升级，以及生成项目的独立运行。
- React + Ant Design 页面物料，编辑和运行入口按项目技术栈加载。

## 使用边界

桌面设置当前支持 DeepSeek 的 `deepseek-flash` 和 `deepseek-v4-pro`。需要自行配置有效 API Key；模型调用使用外部服务，并可能产生供应商费用。

“本地优先”指项目文件和编辑状态保存在本地，不表示 AI 请求完全离线。不要在提示词或页面内容中放入不希望发送给模型的信息。

浏览器模式是开发宿主，没有原生目录选择器和桌面凭据存储。生产远程部署、浏览器模板下载与导入尚未实现，不能只部署工作台静态文件就获得完整服务。

页面、布局和物料契约使用各自明确支持的版本。内部 SQLite 存储版本为 2，升级保留页面会话、消息和序列；它不转换项目 Schema 或应用外壳。未知或不受支持的数据版本会被拒绝，遇到不兼容错误时保留原数据并核对版本，不通过删除数据库处理。

逻辑流的编辑、预览执行和独立项目执行已接通，使用方式见[逻辑流与函数配置](/guide/flow-editor)。目前没有第二套 React 物料、Vue 或物料市场。

布局当前面向新建项目，名称固定，开关对全部页面生效，不支持多个布局或单页覆盖。工作台预览当前仅使用 Working 草稿；独立项目用于验证已应用效果。功能与限制见[布局配置](/guide/layout)。
