# 项目配置与布局

项目「… → 编辑」中可启用布局配置，启用后点击项目下的「布局配置」在工作区打开。面板采用左侧布局效果、右侧配置表单，支持左右、顶部、混合布局，标题、Logo、父子菜单及排序/隐藏、首页、404 和页面布局开关。配置直接保存到 `origamix.project.json` 的必填 `shell`、`layout`、`routing`，使用清单哈希检测冲突，失败保留输入。未配置菜单时只在设置界面显示示例数据；显式空菜单保持为空。

新建项目只填写名称、标识、页面目录、生成位置和启用布局；默认 Browser 路由、根访问前缀和混合布局。关闭布局保留配置，首页和 404 继续有效。引用使用稳定 pageId，删除关联页面前需移除引用。

页面 Agent、可视化编辑和页面预览继续使用 Working → 显式保存 Revision → 显式 Apply。项目设置不经过页面版本流程，不使用布局 Schema 或页面 Agent 写入工具。平台不提供项目预览；完整菜单、路由和业务行为在真实生成项目中验证。设置中的布局示意使用项目草稿，生成项目使用 Template 自带的 Ant Design 应用外壳。

布局 AI 助手与表单共用一份临时草稿，AI 修改经过校验后即时展示，点击「保存配置」才写入项目。

## 使用步骤

1. 创建项目时填写项目名称、标识、页面目录路径和项目生成位置，可选择启用应用布局。
2. 在项目「… → 编辑」中启用布局配置，然后点击项目下的「布局配置」。工作区左侧展示布局效果，右侧修改配置。
3. 选择左右、顶部或混合布局，设置标题和 Logo。未配置菜单时显示带标记的示例数据。
4. 添加菜单，选择页面、标题、父级和是否隐藏；通过上下按钮调整顺序。删除父菜单也会移除它的子菜单草稿，保存后才写入项目。
5. 选择首页和 404，按需关闭个别页面的应用布局。404 未指定时使用模板默认页面。
6. 点击顶部操作栏的「保存配置」更新项目清单。保存失败时保留输入。文件发生冲突时，点击「读取最新配置并核对草稿」。独立修改会合并到草稿，双方都改过的设置由你选择保留哪一份，再显式保存。
7. 页面内容在页面 Agent 或可视化编辑器中修改，页面预览查看草稿；完整路由和业务效果在真实项目中验证。

Logo 的项目根路径资源需放入项目 public 目录；布局效果不读取项目任意文件。AI 助手只能读取配置和提交草稿，不会创建页面、修改页面 Schema 或自动保存。

布局配置右侧可切换「AI 助手」与「表单配置」。助手使用与页面 Agent 相同的模型、凭据、流式引擎和预算控制；每次携带最新配置及真实页面清单，结果绑定项目与草稿版本。生成期间若手工改动表单，旧结果不会覆盖新草稿。停止、断线和保存失败保留配置；不会自动重发模型请求。当前配置草稿及布局对话仅保留在打开的工作区会话中，关闭标签或退出后不恢复，未保存时请先保存。
