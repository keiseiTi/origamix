# 当前能力与限制

当前阶段通过获取源码、安装依赖和本地启动来使用 Origamix。官网暂不提供安装包。

## 已有能力

- Electron 桌面工作台与本地目录授权。
- 页面可视化编辑、Agent 对话和沙箱预览。
- 保留 Working 草稿、显式保存版本、查看和恢复历史。
- 显式应用到本地项目，以及生成项目的独立运行。
- Ant Design 页面物料。

## 使用边界

桌面设置当前支持 DeepSeek 的 `deepseek-flash` 和 `deepseek-v4-pro`。需要自行配置有效 API Key；模型调用使用外部服务，并可能产生供应商费用。

“本地优先”指项目文件和编辑状态保存在本地，不表示 AI 请求完全离线。不要在提示词或页面内容中放入不希望发送给模型的信息。

浏览器模式是开发宿主，没有原生目录选择器和桌面凭据存储。生产远程部署、浏览器模板下载与导入尚未实现，不能只部署工作台静态文件就获得完整服务。

当前没有自动数据库迁移。遇到不兼容错误时保留原数据，先核对代码版本。
