# 页面预览

在页面工具栏点击「预览」。工作台先提交当前页的待保留草稿，提交失败时停留在原视图并保留草稿。进入后可实际操作组件并检查[逻辑流](/guide/flow-editor)的条件分支、函数返回值和异步请求。

- 点击「刷新页面预览」重新读取当前页 Working。读取失败时可重试，已有画面会保留。
- 点击「退出预览」返回该页之前的对话或编辑模式。
- 预览中的运行状态只在本次会话中生效。保存版本和[应用到项目](/guide/apply)仍由用户显式触发。

物料加载或渲染失败时，可根据界面提示检查物料版本和页面属性，再重试。预览 iframe 接收页面快照，无后端凭据与桌面桥接。

要检查[项目布局](/guide/layout)、跨页导航、首页、404 或部署路径，请保存并应用页面，再[运行生成项目](/start/generated-project)。布局设置在项目设置里单独保存。
