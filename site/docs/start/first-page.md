# 创建第一个页面

## 1. 配置模型

在桌面设置中配置 DeepSeek API Key 和模型。当前可选 `deepseek-flash` 或 `deepseek-v4-pro`，默认前者。保存设置后，新会话运行使用新选择。

## 2. 选择本地目录

选择用于项目的目录，首次尝试建议使用专门的空目录。有项目清单时打开已有项目，没有清单时按提示填写初始化信息。

## 3. 创建并编辑页面

创建页面后，进入编辑器添加组件，或在 Agent 会话中描述需求。例如：

> 为当前页面添加一个标题和一个按钮，标题写“我的第一个页面”，按钮写“开始”。

这是提示词示例，实际结果以当前物料和模型执行为准。查看执行结果，再通过属性面板调整内容。

## 4. 预览并保存

打开预览确认页面。点击“保存版本”创建检查点，再点击“应用到项目”。成功后，目标页面的 `schema.json` 才更新。

预览成功不代表已经应用，保存版本也不会自动更新生成项目。

## 5. 独立运行

进入[运行生成项目](/start/generated-project)，在生成项目目录安装依赖并启动页面。
