# 完整应用预览

页面和「布局配置」的预览按钮都打开完整应用。启用[项目布局](/guide/layout)时，当前页面显示在布局的页面内容区中；关闭布局时直接渲染页面。

## 使用预览

进入前，工作台先提交该项目已打开编辑器的草稿。提交失败时保留编辑视图；成功后读取当前布局、页面目录和各页面的 Working，形成只读应用快照。

- 从页面进入时，初始显示该页面；从布局配置进入时，默认显示 Home 或项目第一个页面。
- 通过布局中的导航或顶部页面选择切换页面，工作台标签不会随之切换。
- 点击「刷新应用预览」重新读取快照；失败时显示重试入口，并保留上次快照。
- 点击「退出预览」回到之前的对话或编辑模式。项目没有页面时，先退出并创建页面。

预览使用草稿，不创建版本，也不应用到真实项目。页面内导航使用同一快照，各文档带有自身的版本和 hash；当前不提供跨文档事务性截取，也没有已应用模式切换。

## 检查内容与事件

检查公共布局、内容区、导航选中项和各页面内容。布局与页面使用独立节点表，同名节点不会因此成为同一编辑对象。

在业务页面中实际触发按钮等组件的事件，验证[逻辑流](/guide/flow-editor)的条件分支、函数返回值与异步请求。运行时的元素状态和变量变化不会反向保存为 Working 编辑。布局首期不支持业务流程和事件绑定。

## 渲染错误与隔离

未知物料需要核对 Schema 类型与物料注册；渲染失败需要核对属性和组件。错误会保留可见反馈，之前的草稿不会因此被覆盖。

iframe 只接收工作台校验后的快照，没有后端凭据、桌面桥接或项目写权限。页面自己的运行请求仍取决于业务接口和浏览器网络环境。组合渲染结果绑定布局和页面身份；当前不把布局组合错误写成单页诊断。

## 检查已应用效果

要在独立项目中看到修改，分别保存并应用页面和布局，然后[运行生成项目](/start/generated-project)。独立应用只读取已应用文件，不读取 `.origamix/` 草稿。

工作台预览不能替代独立项目的运行与部署检查，尤其是自定义业务源码、浏览器历史路由和静态服务器回退。继续阅读[应用到项目](/guide/apply)。
