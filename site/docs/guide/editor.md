# 可视化编辑

## 选择物料

在页面编辑器的物料面板选择当前提供的组件。页面物料来自 Ant Design，具体开放组件与属性以面板为准。

## 调整页面

添加组件后选择目标，通过属性面板修改内容与配置，在画布中检查布局。可以继续完善 Agent 已经修改的同一页面，无需复制出另一份页面数据。

编辑器将变化提交给 Server，成功后自动保留为 Working 草稿。普通编辑不会创建历史版本，也不会写入生成项目。

## 大纲与事件

切换到“大纲树”可以查看页面层级并选择元素。每个元素下面显示物料声明的事件，例如按钮的“初始化”和“点击事件”，并随元素一起展开或折叠。点击事件可进入该元素对应的逻辑流。

顶部“视图 / 逻辑”切换的是同一页面的两种编辑模式。逻辑图中的节点编排、属性和连线变化同样自动进入 Working 队列；详细操作见[逻辑流与函数配置](/guide/flow-editor)。

## 检查保存反馈

草稿保留失败时，界面保留当前编辑内容，并可能阻止切换页面或预览。先查看错误并重试，避免离开页面丢失尚未提交的编辑。

发生版本冲突时读取最新状态后再调整，不要用旧内容覆盖新的 Working。
