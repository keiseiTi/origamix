# 工作方式

一次完整的页面工作流包含四个阶段。

## 1. 打开项目与页面

通过桌面应用选择本地目录。已有项目清单时打开项目；没有清单时按提示初始化，再创建或打开页面。

## 2. 编辑与预览

Agent 和可视化编辑器都修改同一份 Working 草稿。成功的编辑会自动保留；预览渲染当前草稿。

## 3. 保存版本

确认结果后，点击“保存版本”，为当前草稿创建不可变的 Revision 检查点。普通编辑不会自动创建版本。

## 4. 应用到项目

点击“应用到项目”，将当前已保存且没有新增草稿修改的版本写入目标页面的 `schema.json`。生成项目读取这份文件。

| 状态                 | 工作台             | 生成项目       |
| -------------------- | ------------------ | -------------- |
| 编辑后的草稿         | 显示新内容         | 仍使用原内容   |
| 已保存版本，尚未应用 | 可以查看或恢复版本 | 仍使用原内容   |
| 应用成功             | 显示应用状态       | 使用已应用内容 |

继续阅读[草稿、版本与历史](/guide/history)与[应用到项目](/guide/apply)。
