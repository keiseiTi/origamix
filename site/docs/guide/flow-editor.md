# 逻辑流与函数配置

## 从元素事件进入

在编辑器的“大纲树”展开元素，下面会显示当前物料支持的事件，例如按钮的“初始化”和“点击事件”。点击事件进入对应逻辑流；也可以通过属性面板的“事件”或顶部“逻辑”视图进入。相同名称的事件仍分别属于各自的元素。

逻辑模式左侧提供页面事件树与节点面板，中间配置连线，右侧编辑选中节点的参数。节点以名称或别名展示，不在配置面板显示内部类型与 ID。

## 编排节点

把节点拖入画布，或在节点面板聚焦后按 Enter / Space 添加。通过锚点连接执行顺序。开始节点不能删除，流程不能形成循环；条件节点的真、假分支各最多连接一个后续节点。

| 节点                | 用途                                           |
| ------------------- | ---------------------------------------------- |
| 开始                | 事件触发后的执行入口                           |
| 接口请求            | 配置 URL、请求方法、请求头、查询参数和请求体   |
| 自定义 JS           | 执行函数并返回结果                             |
| 设置元素属性        | 选择目标元素、属性和新值                       |
| 触发元素方法        | 调用物料公开的上下文方法，传入一个求值后的参数 |
| 显隐元素            | 批量显示或隐藏页面元素                         |
| 条件判断            | 根据表达式或函数结果选择真、假分支             |
| 设置全局变量        | 更新当前页面的全局变量                         |
| 打开 / 关闭弹窗抽屉 | 控制页面中的 Modal 或 Drawer                   |

在画布中选中节点或连线后，可用 Delete / Backspace 删除；右侧配置面板没有“删除节点”按钮。画布工具栏提供撤销、重做和缩放。快捷键只在画布内操作，避免编辑输入框时误删节点。

节点位置、属性、增删及连线变化都会进入同一 Working 队列。草稿保留失败时保留当前编辑内容并显示错误；继续输入不会自动重试一次结果不明确的写入。

## 选择值的配置方式

根据字段选择字符串、数字、布尔值、空值、上下文、表达式或函数。当前没有额外的 JSON 值类型。

请求 URL 可使用字符串、表达式或函数。请求头、查询参数、请求体通过函数返回值配置；条件判断使用表达式或函数，不再单独选择比较操作符。显隐设置支持布尔值、表达式或函数。

## 配置函数参数

点击“编辑…函数”后，在弹窗中选择属性并编辑函数体。

1. 默认保留一行参数；选择框提示“请选择属性”。
2. 来源先显示完整属性名称，再显示别名（有则显示）、元素类型和来源种类标签，例如“按钮文本 / 提交订单 / 按钮 / 元素”。接口节点结果标记为“接口”，全局变量标记为“全局变量”。
3. 选择来源后自动填入参数名，可在右侧修改。函数体通过这个参数名访问取值。
4. 每行的加号在当前行后新增参数；多行时显示删除按钮，至少保留一行。来源可清空，下拉列表限高并内部滚动，不提供上下文路径输入。
5. 使用 `return` 返回结果，点击“确认函数”提交；取消会丢弃弹窗内尚未确认的修改，重新打开读取已提交配置。

完全空白的参数行不会保存为函数参数，因此无参数函数也能确认。已填写的参数必须有有效且唯一的名称和来源；不完整或重复时会提示补全。

例如选择按钮文本属性，并将参数命名为 `text`，函数体可以写为：

```js
return text + '，已提交';
```

无参数的请求头函数可以写为：

```js
return { 'Content-Type': 'application/json' };
```

## 在预览中验证

函数配置只是页面数据；Editor 和 Server 不执行代码。进入预览后，由 Runtime 在页面环境中解析参数、执行函数并等待异步结果；独立生成项目使用同一 Runtime。

请求节点仅接受 HTTP(S)，不隐式携带工作台凭据，使用 10 秒超时且不自动跟随重定向。返回值包含 `ok`、`status`、`data` 和 `error`；请求失败需要通过后续条件处理。其他脚本执行错误会显示提示并停止本次事件后续动作。

运行时修改的元素状态和变量不会写回 Working。编辑逻辑流才会保留草稿；[保存版本](/guide/history)和[应用到项目](/guide/apply)仍需明确操作。

页面代码在预览沙箱 iframe 或生成项目自身环境中执行，函数求值器本身不是安全沙箱。仅运行你理解并信任的代码。
