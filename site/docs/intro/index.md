# 什么是 Origamix

Origamix 是 AI 驱动、本地优先的低代码编辑器。你可以通过对话修改页面，也可以在可视化编辑器中调整组件和属性，在同一个工作台中预览结果。

它适合希望结合 AI 与组件化编辑来搭建 React 页面的开发者。当前提供 Ant Design 页面物料，生成项目可以脱离编辑器独立运行。

## 三个核心能力

- **对话编辑**：让 Agent 根据当前页面和可用物料修改页面。
- **可视化调整**：在编辑器中添加组件、调整布局与属性，继续完善 AI 的结果。
- **本地项目**：在授权目录中管理页面，确认版本后更新真实项目。
