# 草稿、版本与历史

## 三种状态

| 名称          | 含义                     | 何时变化                         |
| ------------- | ------------------------ | -------------------------------- |
| Working 草稿  | 当前唯一可编辑的页面数据 | Agent 或编辑器成功修改、历史恢复 |
| Revision 版本 | 不可变的页面检查点       | 明确点击“保存版本”               |
| 项目 Schema   | 生成项目实际读取的数据   | 初始化或明确“应用到项目”         |

## 保存版本

点击“保存版本”，或使用 Ctrl / Cmd + S，将当前 Working 保存为 Revision。保存相同状态不会重复创建版本。

“版本已保存 · 待应用”意味着版本已经保留，但生成项目仍使用之前的内容。

## 查看与恢复历史

历史按页面列出版本；查看某个版本读取其不可变快照。确认恢复后，该快照成为当前 Working，并处于未保存草稿状态。

恢复不会保存新版本，也不会应用。检查结果后仍需要依次保存版本、应用到项目。

## 外部项目内容

“重新读取项目内容”与历史恢复不同：它确认后用目标项目内容替换 Working，放弃当前未应用修改。操作前明确要保留哪份内容。
