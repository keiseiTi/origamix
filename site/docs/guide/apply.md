# 应用到项目

## 应用前的条件

当前 Working 必须已明确保存为版本，并且没有新的草稿修改。编辑后先预览，再保存版本，最后点击“应用到项目”。

Apply 更新授权项目中当前页面的目标 `schema.json`，不重写普通页面入口、样式或业务代码。

## 确认结果

成功后检查应用状态，再在生成项目中运行页面。单纯预览成功或保存版本成功，不等于应用成功。

## 目标文件被外部修改

“项目文件已变化”表示文件在 Origamix 之外发生了修改。先比较目标文件与当前草稿，决定保留哪一份。

需要读取目标项目时使用显式“重新读取项目内容”，并确认会放弃未应用修改。不要通过反复点击应用绕过冲突。

## 结果不明确

“应用结果待确认”或连接中断时，写入可能已经发生。先通过页面状态确认结果，并使用已有操作的重试入口。客户端保留同一请求身份，避免重试变成第二次逻辑写入。

目标文件缺失、路径无效或无权限时，修正问题后再操作，不要直接删除本地草稿与恢复记录。
