# 常见问题

## 为什么工作台变了，生成项目没有变化？

页面编辑更新 Working 草稿。对页面执行「保存版本」和「应用到项目」后，生成项目才会读到新的页面内容。MySQL 项目在项目菜单选择「同步到本地」，也可以下载新的项目 ZIP。布局修改另行点击「保存配置」。

## 在哪里查看完整菜单、跨页导航和 404？

在[生成项目](/start/generated-project)中运行 `pnpm dev`。「页面预览」用于操作当前页面草稿，「布局配置」中的「查看效果」用于核对布局示意。

## 修改物料后，需要重新构建 App 吗？

开发时，Materials 构建完成后，启动器会同步构建后端校验使用的 Manifest、准备模板依赖并重启后端。桌面窗口保留，工作台刷新后加载新物料，不需要先打包 App。正式交付运行根 `pnpm build`，其中会重新构建 App。已有用户项目的依赖不会自动更新，工作台不提供依赖升级入口。

## 开发时为什么桌面会重启？

Shared、Runtime、Materials、Server、Main/Preload 等源码变化会触发依赖构建和自动重启；App、Editor、UI 保持 HMR。调试 Agent 或长时间编辑时，在开发终端输入 `p` 并回车暂停，再次输入恢复。重启可能中断未提交内容，完整行为见[开发与验证](/architecture/development#源码更新与自动重启)。

## 不配置 API Key 能编辑吗？

普通可视化编辑不依赖模型调用；使用 Agent 需要有效的模型配置和凭据。

## 能在浏览器直接使用吗？

本机开发运行 `pnpm dev:web`。单用户正式部署使用 `pnpm build:web` 和 `pnpm start:web`。MySQL 项目可通过项目菜单同步到本机或导出完整 ZIP。见[正式 Web 宿主](/architecture/development#正式-web-宿主)。

## 可以离开 Origamix 运行页面吗？

可以。生成项目自带运行入口、依赖和工具配置，安装后可独立开发和构建。参见[运行生成项目](/start/generated-project)。

## 草稿保留失败怎么办？

保持当前页面打开，查看错误并点击「重试保存草稿」。工作台会核对上次提交的结果，再保存断线后的编辑。如果服务器内容来自其他修改，先保留需要的本地改动，再选择「重试加载」并确认采用服务器版本。关闭原窗口会丢失只留在内存里的编辑。

## 连接断开后能再次点击应用吗？

先确认持久化状态，再使用原操作的重试入口。连接断开不等于写入失败，见[应用到项目](/guide/apply)。

## 生成项目安装报 workspace:* 或找不到指定版本？

确认使用的是 Origamix 生成的完整项目。当前生成项目使用固定的 npm 版本；如果找不到指定版本，请核对所用 registry 中是否已发布该版本。

## 如何提交问题？

在 [GitHub Issues](https://github.com/keiseiTi/origamix/issues) 描述代码版本、操作步骤、预期结果和实际错误。去掉 API Key、认证信息与私人项目内容。
