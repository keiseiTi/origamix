# 模型配置与 AI 编辑

## 配置模型

桌面设置支持 DeepSeek 的 `deepseek-flash` 和 `deepseek-v4-pro`。API Key 由桌面宿主管理，使用系统加密能力保存；系统加密不可用时保存新 Key 会报错。

修改设置对下一次 Agent Run 生效，已启动的 Run 保留原模型。

## 描述当前页面的需求

先打开目标页面，再提交需求。建议指出具体组件、内容和布局，并把较大的修改拆成可检查的步骤：

> 将当前页面标题改为“项目概览”，在标题下面添加一个说明段落。

Agent 根据页面基线和物料清单执行，成功提交后更新 Working 草稿。它不会自动保存 Revision 或应用到项目。

## 澄清与检查

需要澄清时按界面选择目标；页面发生变化后，旧选择可能过期，需要重新提出需求。执行完成后检查页面并预览，再决定是否保存版本。

## 失败与恢复

Key 无效或模型请求失败时，查看错误并修正配置。断线或后端重启后，界面从持久化 Run、消息和 Working 恢复；不会自动重做模型请求。

恢复状态加载期间部分操作可能暂时禁用。使用界面的重试入口确认状态，避免连续提交同一个修改。
