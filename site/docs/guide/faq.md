# 常见问题

## 为什么工作台变了，生成项目没有变化？

编辑只更新 Working 草稿。确认已经保存版本并应用到项目，再检查对应页面的目标 Schema。

## 不配置 API Key 能编辑吗？

普通可视化编辑不依赖模型调用；使用 Agent 需要有效的模型配置和凭据。

## 能在浏览器直接使用吗？

仓库提供 `pnpm dev:web` 开发宿主，但没有原生目录选择器和桌面凭据存储。它不是完整的生产远程部署方案。配置方式见[开发与验证](/architecture/development)。

## 可以离开 Origamix 运行页面吗？

可以。生成项目自带运行入口、依赖和工具配置，安装后可独立开发和构建。参见[运行生成项目](/start/generated-project)。

## 草稿保留失败怎么办？

保留当前编辑，查看错误并使用重试入口。不要把切换页面或关闭应用当作恢复方法。

## 连接断开后能再次点击应用吗？

先确认持久化状态，再使用原操作的重试入口。连接断开不等于写入失败，见[应用到项目](/guide/apply)。

## 生成项目安装报 workspace:* 或找不到 vendor 文件？

确认使用的是应用生成的完整项目，而不是直接复制仓库原始 Template。保留 `vendor/*.tgz` 和项目配置。

## 如何提交问题？

在 [GitHub Issues](https://github.com/keiseiTi/origamix/issues) 描述代码版本、操作步骤、预期结果和实际错误。去掉 API Key、认证信息与私人项目内容。
