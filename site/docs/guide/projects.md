# 项目与页面

## 打开项目

桌面应用先选择目录，再判断目录中是否存在 `origamix.project.json`。存在清单时打开项目；缺少必要信息时根据提示补充。没有清单时填写初始化信息。

使用明确授权的目录，不要把整个个人主目录作为实验项目。

## 页面与目录

项目清单记录页面和稳定的页面 ID。页面的显示名称用于识别，slug 用于生成目录和路由；目录由 `pageDirectory` 配置，默认位于 `src/pages/`。

页面创建会准备页面入口与初始 Schema。之后的普通编辑只更新保留草稿，显式应用才更新目标 Schema。

## 重新打开

重新打开页面会恢复保留的 Working 草稿，不要求先将草稿应用到真实项目。会话和版本也按项目、页面隔离。

不要只在文件系统中移动页面目录而不更新清单。目标文件缺失、移动或无效时，应先处理错误，避免通过重建整个项目覆盖本地代码。
