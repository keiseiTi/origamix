# 页面预览

预览用于检查当前 Working 草稿的渲染结果。它与编辑器共用 Runtime 渲染核心，并在沙箱 iframe 中运行。

## 使用预览

完成修改并确认草稿保留成功后，进入预览。检查内容、布局和组件行为，再返回编辑器继续调整。

预览不会创建版本，也不会应用到真实项目。要在独立项目中看到新内容，还需要保存版本和应用。

## 渲染错误

未知物料通常需要核对 Schema 类型与物料注册；渲染失败需要核对属性和组件。预览错误应保留可见反馈，不会自动覆盖草稿或写入目标项目。

成功渲染也不能替代独立项目的运行检查，尤其是业务代码和部署路由。

继续阅读[应用到项目](/guide/apply)。

## 检查事件与函数

在预览中实际触发按钮等组件的事件，验证[逻辑流](/guide/flow-editor)的条件分支、函数返回值与异步请求。表单保存成功不代表函数执行成功；运行错误应在预览中处理后再决定保存版本。运行时的元素状态和全局变量变化不会反向保存为 Working 编辑。
